使用須知、更新與資料備份

這是非官方工具入口。每個 App 使用官方 Web 發行版本；入口為繁體中文，App 內的語言及功能由原作者提供。首次開啟可能要下載數十 MB，手機介面、瀏覽器及影音格式支援因 App 而異，建議桌面瀏覽器使用。

App 在新分頁開啟，入口會保留。檔案請透過 App 的儲存／匯出功能下載備份；瀏覽器暫存並非永久備份，亦不會自動同步到其他裝置。不同 App 及同帳戶其他 GitHub Pages 網站共享儲存來源，子目錄並非安全隔離。

網站沒有加入上傳服務或分析追蹤，但各官方 App 的外部連線及功能須以該 App 為準。即時協作、AI 等依賴外部服務的功能不由這個靜態入口提供。

每日自動檢查官方正式 Release；更新通過下載驗證及檢查後才部署。正在編輯時請先匯出文件，再重新開啟新版。新頁面不會強制重載你正在使用的 App。
