# Sources and licenses

Craft Suite Web is an independent, unofficial static launcher by appbuilderlee2.
It is not ArtCraft Launcher and is not affiliated with or endorsed by the ArtCraft team.

All thirteen applications are downloaded unchanged from their respective official
`https://github.com/storytold/<app>` versioned releases. The deployment records
the exact tag, archive URL and SHA-256 in `versions.json`.

PhotoCraft, VectorCraft, FilmCraft, LightCraft, PdfCraft, EffectCraft, DesignCraft,
WordCraft, DeckCraft, GridCraft, CADCraft, SoundCraft and FigCraft retain their
upstream licenses and trademarks. Each deployed application directory includes
the release-tagged LICENSE-MIT and LICENSE-APACHE, and NOTICE / ATTRIBUTION.md
when present. Bundled third-party notices are preserved.

The hub uses its own four-square mark and text monograms, not the official
ArtCraft Launcher trademark. App names are used for identification only.
LightCraft's unused Cargo build directories are excluded where present; the
runtime HTML, JavaScript and WebAssembly are not modified.
